# Support

## Questions

Use [GitHub Discussions](https://github.com/frodo4fingers/mangame/discussions)
for installation, configuration and usage questions. Check the
[README](README.md) first, especially the Linux desktop support notes.

## Bugs

Open a [bug report](https://github.com/frodo4fingers/mangame/issues/new?template=bug_report.yml)
with:

- what happened and what you expected;
- exact reproduction steps;
- operating system and desktop environment;
- how mangame was installed;
- the report from **Settings → Diagnostics**.

Review paths and logs before sharing them. Logs can contain local file names,
source errors and source URLs. The latest release is the supported version.

## Security

Do not open a public issue for a vulnerability. Follow
[SECURITY.md](SECURITY.md) and use a private GitHub security advisory.
